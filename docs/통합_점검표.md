## 3. Team 2 검사 마커 연동 필수 조건

검사 단계(`CONFIRM_INSPECTION`)로 가는 화면 경로는 지역 화면의 학당 표식 하나뿐이다. 다음 중 하나라도 빠지면 정식 검사로 진행할 수 없다.

- [ ] `drawRegion(scene, view, { ox, oy })`가 `{ objs, hit }`를 반환하고, `hit`에 `def.id === 'hall'`인 항목(`x`, `y` 포함)이 있다. 없으면 트럭 도착 시 `hall.x`에서 TypeError가 난다.
- [ ] `pending === 'INSPECTION'`이면 트럭이 학당에 도착한 뒤 표식을 그리고, 표식 클릭 시 `game.events.emit('pt:inspect')`를 보낸다. UI는 이 신호로 검사 패널(`inspect` 버튼)을 연다.
- [ ] 표식을 그릴 때 `registry.set('markerPos', { x, y, w, h })` 후 `game.events.emit('pt:marker')`를 보낸다. 다시 그릴 때와 Scene 종료(`shutdown`) 시 `markerPos`를 `null`로 바꾸고 `pt:marker`를 보낸다.
- [ ] 건물 클릭 정보 팝업 신호 `pt:info { title, lines }`를 유지한다(필수는 아니지만 UI가 받는다).
- [ ] 지역 화면은 `watchView`로만 상태를 읽는다(현재 `[region.hallLit, pending, phase]`).

## 7. Team 2·3 전달 사항

**공통**

- 상태 읽기는 `TYCOON.app.store.getState()`(또는 `watchView`), 변경은 `TYCOON.app.store.dispatch()`만 사용한다. `TYCOON.app.flow.state`, System, GameState setter를 직접 쓰지 않는다.
- `view()` 필드는 추가만 한다. 필요한 값이 없으면 화면에서 계산하지 말고 팀원 1에게 요청한다.
- `watchView`는 GameState 변경에만 반응한다. meta(`hintsOn`, `seenDialogs`)와 `fatal`은 `store.subscribe`로 받는다.

**Team 2 (월드·에셋)**

- 3장 검사 마커 조건은 진행에 필수다.
- 실제 그림은 기존 텍스처 키(`truck`, `colleague_sit`, `<팔레트>_<자세>` 등)로 `ASSETS`에 등록하면 된다. 사용처 코드는 바꾸지 않는다. 일부만 등록해도 나머지 키는 임시 그림으로 표시된다(5장). 이 동작은 `team1` 수정이 `develop`에 병합된 뒤부터 적용된다.
- 인물은 키 하나에 이미지 하나(`resident_a_walk0` 등)다. 스프라이트시트는 지원하지 않는다.
- 에셋은 `src/assets/**`에 두고 `ASSETS`에 `index.html` 기준 상대 경로로 등록한다. 외부 주소는 오프라인 ZIP에서 실패한다. `PreloadScene`은 `image`·`audio` 형식만 불러온다.

**Team 3 (UI·대화·엔딩)**

- `dispatch()` 실패는 `{ ok: false, error, reason, code? }`다. 분기는 `reason`, 표시는 `error` 또는 `reason`별 문구. `error` 문자열은 비교하지 않는다.
- `MARK_DIALOG_SEEN`은 비어 있지 않은 문자열 ID만 받는다(아니면 `NOT_FOUND`).
- 새 게임은 현재 `TYCOON.app.flow.newGame()` 직접 호출 + `pendingEvents = ['GAME_STARTED']`(`store.newGame()`은 미정).
- 실패한 명령의 결과 이벤트(`CONTRACT_REJECTED`, 미통과 `INSPECTION_COMPLETED`)는 전달되지 않는다. 실패는 반환값으로 처리한다.
- 새로고침 복원 시 `UIScene.create()`가 상태로 화면을 구성하고 `pendingEvents`는 비어 있다(대화를 다시 띄우지 않는다).
- 4장 E2E 의존 항목을 바꿀 때 팀원 1에게 알린다.
- END 저장으로 접속하면 `UIScene`·`OfficeScene`을 거치지 않고 타이틀이 열린다(2026-11-13 결정, API명세서 6-5). END 완료 화면은 같은 세션에서만 보인다.
